Teorema de Rouché-Frobenius

Permite clasificar un sistema de ecuaciones lineales estudiando los rangos de la matriz de coeficientes $A$ y la matriz ampliada $A^*$.

Clasificación de Sistemas ($n$ incógnitas)

  • SCD (Compatible Determinado): $\text{rg}(A) = \text{rg}(A^*) = n \implies$ Solución única.
  • SCI (Compatible Indeterminado): $\text{rg}(A) = \text{rg}(A^*) < n \implies$ Infinitas soluciones.
  • SI (Incompatible): $\text{rg}(A) \neq \text{rg}(A^*) \implies$ Sin solución.

Ejercicios Resueltos

Ejercicio 1: Clasifica el sistema según el Teorema de Rouché sabiendo que $n = 3$ incógnitas, $\text{rg}(A) = 2$ y $\text{rg}(A^*) = 2$.

Solución paso a paso

Como $\text{rg}(A) = \text{rg}(A^*) = 2$, el sistema es Compatible. Sin embargo, al ser el rango menor que el número de incógnitas ($2 < 3$), el sistema es Sistema Compatible Indeterminado (SCI), con infinitas soluciones dependientes de $3 - 2 = 1$ parámetro.
