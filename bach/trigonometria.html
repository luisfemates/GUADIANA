Teoremas del Seno y del Coseno

Para resolver triángulos cualesquiera (no necesariamente rectángulos), utilizamos dos teoremas fundamentales que relacionan sus lados $a, b, c$ con los ángulos opuestos $A, B, C$.

Teorema del Seno

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

Teorema del Coseno

$$a^2 = b^2 + c^2 - 2bc \cos A$$ $$b^2 = a^2 + c^2 - 2ac \cos B$$ $$c^2 = a^2 + b^2 - 2ab \cos C$$

Ejercicios Resueltos

Ejercicio 1: En un triángulo conocemos $b = 8\text{ cm}$, $c = 5\text{ cm}$ y el ángulo comprendido $A = 60^\circ$. Calcula el lado $a$.

Solución paso a paso

Aplicamos directamente el teorema del coseno para el lado $a$:

$$a^2 = 8^2 + 5^2 - 2(8)(5)\cos(60^\circ)$$

Como $\cos(60^\circ) = 0.5$:

$$a^2 = 64 + 25 - 80(0.5) = 89 - 40 = 49$$ $$a = \sqrt{49} = 7\text{ cm}$$
