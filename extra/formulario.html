Formulario Completo para la PAU / Selectividad

Resumen de las fórmulas más importantes de Álgebra, Análisis y Geometría necesarias para superar las pruebas de acceso a la universidad.

1. Análisis y Cálculo

Regla de Barrow (Integrales Definidas):

$$\int_a^b f(x) \, dx = [F(x)]_a^b = F(b) - F(a)$$

Derivada de un producto y cociente:

$$(u \cdot v)' = u'v + uv' \quad | \quad \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$$

2. Geometría 3D

Distancia de un punto $P(x_0,y_0,z_0)$ a un plano $\pi: Ax+By+Cz+D=0$:

$$d(P, \pi) = \frac{|A x_0 + B y_0 + C z_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$
